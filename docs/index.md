# kube-homelab

A Kubernetes home lab on Proxmox, built one lesson at a time. Each lesson deploys something useful and documents the concepts behind it.

Work through the lessons in order; side lessons can be done whenever they're useful. Every page has a table of contents on the right, and search is at the top.

## The repository

| Folder | Contents |
|---|---|
| [`docs/learning/`](https://github.com/vuongsteven/kube-homelab/tree/main/docs/learning) | Kubernetes lesson write-ups |
| [`docs/side-lessons/`](https://github.com/vuongsteven/kube-homelab/tree/main/docs/side-lessons) | Side lesson write-ups |
| [`kubernetes/`](https://github.com/vuongsteven/kube-homelab/tree/main/kubernetes) | Manifests, one folder per app |
| [`terraform/`](https://github.com/vuongsteven/kube-homelab/tree/main/terraform) | Terraform, one folder per project |

Kubeconfig files, credentials, `terraform.tfvars` and Terraform state stay out of the repository.
